# NotesInformesFCBQ

Calcula la nota numèrica dels informes d'arbitratge de l'FCBQ (plantilla de pesos 26-27).

**Fes-la servir aquí:** https://adriasf.github.io/NotesInformesFCBQ/

- Arrossega un o més informes en PDF i obtens la nota final, els punts de cada bloc i la mitjana.
- Si algun ítem no es detecta, es pot corregir a mà i la nota es recalcula.
- Els PDF es llegeixen al navegador: no s'envien ni es guarden enlloc.

## Sistema de puntuació

Òptim 100 % · Acceptable 60 % · Millorable 30 % · No satisfactori 0 % · No valorable no compta.

Nota del bloc = pes del bloc × Σ(pes ítem × valor) ÷ Σ pes dels ítems valorables.
Blocs: Aspectes genèrics 7 · Tècnica d'arbitratge 25 · Criteri 43 · Control del partit 25.

Nota final = suma dels blocs × multiplicadors (errades decisives, regles de joc, dificultat, actitud, autocrítica).
